# MCA Assistant — association notes

Everything the assistant knows that is **not** in the rule books goes here:
decisions the committee has made, clarifications, things that changed after the
books were printed, and anything else worth it knowing.

Editing this file and merging to `main` deploys it. Nothing links to it from
the website — it is only ever read by the assistant.

## How the assistant treats this file

1. **The rule books come first.** Where this file and a rule book disagree, the
   rule book wins and the assistant says so.
2. **This file beats the assistant's general knowledge.** If something is here
   and nowhere else, it is treated as true.
3. **It cites this as an association note**, not as a rule book section, so
   nobody mistakes a committee decision for a printed rule.

## Writing notes

Keep each note short and specific. Say what is true, not what to say. Include a
date when it matters. Delete a note once it is out of date or has made it into
the rule book — a stale note here is worse than no note.
